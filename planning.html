2 Setup Supabase: tabelle + storage

Cosa fare nel tuo nuovo account Supabase

3 fasi sequenziali. Tempo totale: ~15 minuti. Tutto via interfaccia grafica.

A
Crea l'account e il progetto
~5 min
1
Vai su supabase.com → Start your project → registrati con la tua email dedicata (quella che vuoi tenere separata dagli altri 2 account).
2
Una volta dentro la dashboard, click "New project". Compila:
• Name: email-agent (o quello che preferisci)
• Database password: generala random e SALVALA in un password manager. È diversa dalle password mail. Ti servirà solo se accederai al DB direttamente.
• Region: Frankfurt (eu-central-1)
• Plan: Free
3
Aspetta 1-2 minuti che il progetto si avvii (vedrai una rotellina). Quando vedi la dashboard del progetto sei pronto per la fase B.
B
Esegui il file SQL: crea le 4 tabelle
~3 min
SQL
email_agent_schema.sql
File pronto da incollare. Crea 4 tabelle, 1 vista, 5 indici, e popola aziende + caselle email.
1
Nel menu laterale a sinistra, click sull'icona SQL Editor (icona </>).
Sidebar ▸ SQL Editor
2
Click "+ New query" in alto a sinistra.
3
Apri il file email_agent_schema.sql nel tuo editor di testo (anche Blocco Note va bene), copia tutto e incollalo nell'area dello SQL Editor di Supabase.
4
Click "Run" in basso a destra (oppure Ctrl+Enter / Cmd+Enter).
Come capire se è andato tutto bene
In basso, sotto l'editor, deve apparire un messaggio verde "Success. No rows returned". Se vedi errori in rosso fai screenshot e mandameli, sistemiamo insieme.
5
Verifica visiva (opzionale ma consigliata):
Vai su Sidebar ▸ Table Editor. Devi vedere 4 tabelle: aziende, caselle_email, inbox_raw, inbox_triage. Click su aziende: dovresti vedere 3 righe (EDV, EDC, HON). Click su caselle_email: dovresti vedere 5 righe.
C
Crea il bucket Storage per gli allegati
~2 min
1
Nel menu laterale, click Storage.
Sidebar ▸ Storage
2
Click "New bucket" in alto.
3
Compila:
• Name: email-attachments
• Public bucket: NO (lascialo OFF — gli allegati delle email non devono essere pubblici!)
• Tutto il resto lascia di default.
Click "Create bucket".
Importante: il bucket DEVE essere privato. Se per errore lo crei pubblico, gli allegati delle tue mail (incluse fatture, contratti, dati sensibili) sarebbero accessibili da chiunque conoscesse il link.
D
Recupera le credenziali del progetto
~3 min
1
Nel menu laterale, click sull'icona ingranaggio (Project Settings) in basso a sinistra → poi API.
Settings ▸ API
2
Annota su un foglio (o password manager) i seguenti valori. Ti serviranno allo Step 3 e Step 6.
CosaDove lo trovi
Project URL
è pubblico, non sensibile		 Box "Project URL" → click "Copy"
https://xxxxxx.supabase.co
service_role key
SEGRETA, mai condividere		 Box "Project API keys" → riga "service_role" → click "Reveal" → "Copy"
eyJhbGciOi... (lunga ~200 caratteri)
Sicurezza service_role key: questa chiave permette a chi la possiede di leggere/scrivere/cancellare qualunque cosa nel tuo database, bypassando tutte le protezioni. Trattala come la password della tua banca: salvala in un password manager, mai in chat con me, mai in Slack/Email/WhatsApp, mai in un documento Google. La useremo SOLO nei GitHub Secrets (cifrati) e nel pannello LangSmith (cifrato).
Quando hai finito tutte e 4 le fasi
Scrivimi: "fatto, ho il Project URL"
Non incollarmi né l'URL né la service_role key: mi basta sapere che le hai. Allo Step 3 (script Python che scarica le mail) ti dirò esattamente dove vanno inserite, in modo che restino sempre cifrate.
